# Mission Control AI

**Autonomous multi-agent operating system for founders, startups, and execution planning.**

Mission Control AI turns one raw business goal into a structured startup execution blueprint using specialized AI agents, consensus scoring, founder copilot workflows, and investor-ready outputs.

## Live Demo

https://mission-control-ai-beryl.vercel.app

## What It Does

Mission Control AI helps founders move from idea to execution faster by coordinating multiple expert agents:

* **Research Agent** — market, competitors, TAM/SAM/SOM
* **Product Agent** — MVP scope, roadmap, technical architecture
* **Strategy Agent** — monetization, pricing, growth model
* **Critic Agent** — risks, compliance gaps, weak points

## Key Features

* Multi-agent startup analysis
* Live mission command dashboard
* Founder Copilot
* Investor Mode

* Consensus scoring

## Local Setup

```bash
git clone https://github.com/softpeak007/mission-control-ai.git
cd mission-control-ai
npm install
```

Create `.env`:

```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

Run locally:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Build for Production

```bash
npm run build
npm run start
```
