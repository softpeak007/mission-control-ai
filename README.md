---

## 🌌 The Problem
**The Ideation-to-Execution Bottleneck.**
In the modern landscape, coming up with ideas is cheap and instantaneous. However, validating a concept, analyzing complex multi-jurisdictional compliance laws, mapping technical product scoping architectures, and evaluating scalable, unit-economic monetization structures takes weeks of painstaking coordination, competitive manual audits, and thousands of dollars in legal or structural consulting fees. 

Developers and startup founders collapse into strategic stagnation before laying down their first line of code.

---

## 🛠️ The Solution
**Mission Control OS: A Multi-Agent Pipeline.**
Mission Control AI bypasses manual gridlocks by coordinating an active computational assembly line of individual agent experts. Instead of struggling with fragile, generic single-prompt text generation, our orchestrator delegates responsibility to specialized sub-agents who analyze, critique, debate, and compile insights sequentially.

The result is an elite blueprint ready for the physical board:
1. **Interactive Command Center**: Track system resources, active missions, and spin up pipelines on-the-fly.
2. **Deterministic Consensus Scores**: Rigorous algorithmic scores reflecting Feasibility, Opportunity, Risk, and Complexity.
3. **Structured Live Logs**: View raw reasoning loops, critic objections, and strategy breakthroughs in a real-time console buffer.
4. **Investor & Hackathon Board Ready**: A beautiful slide deck, pitch summaries, executive memos, and downloadable checklists.

## 🌟 Primary Modules

### 1. Command Center & Active Missions
Deploy new venture concepts using our interactive goal prompt processor. Our custom UI manages ongoing execution pipelines with high-contrast, responsive visual gauges, live terminal logs, and real-time agent state indicators.

### 2. Founder Copilot (Active Memory Layer)
Resides directly adjacent to your agent reports, maintaining persistent, context-rich conversations about your venture goals. It reads consensus findings to answer queries, generate compliance forms, draft intake questionnaires, or propose sandbox structures.

### 3. Investor Mode
Turn raw milestones into investor-grade deliverables with a single click. Includes:
*   **Declassified Venture Memorandums**: Ready-to-copy text blocks with bulletproof executive summaries, funding readiness scores, and investor recommendations.
*   **Deck Carousel**: Keyboard-driven (← / → Keys) responsive slides conveying Problem, Solution, Market Strategy, and Unit Economics.
*   **PDF Print Styles**: Standardized layouts styled for direct physical or digital briefing exports.

### 4. Live Judge Audit Board
A specialized evaluation suite featuring:
*   **Aesthetic Heuristic Scorecards**: Average judges scorecard breakdown based on 10 strict hackathon metrics.
*   **Defensible Live Demo Routine**: Offline-first simulated workflow highlighting progressive state transitions, agent states, and consensus scoring within 20s.

## 🛠️ Technology Stack
*   **Frontend**: React 18 (TypeScript), Vite
*   **Styling**: Tailwind CSS (Sophisticated High-Contrast Slate Theme)

## 🚀 Installation & Local Development

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (v18+) and npm installed.

### 2. Clone and Setup
```bash
# Clone the repository
git clone https://github.com/your-username/mission-control-ai.git
cd mission-control-ai

# Install dependencies
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```env
# Google Gemini API key required for live AI generation
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

### 4. Running the Application
```bash
# Start server and UI in Hot-Reloading Development Mode
npm run dev
```
Open your browser to `http://localhost:3000` to access the console.

### 5. Production Build
```bash
# Compile and bundle the full stack
npm run build

# Start the optimized modular server
npm run start
```
